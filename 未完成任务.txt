未完成任务清单

一、用户门户后端
1. 消息通知接口：任务完成、任务失败、系统告警通知。
2. 门户汇总接口：当前用户任务总数、最近任务、风险概览。
3. 当前用户任务摘要接口：区别于平台管理员全局任务摘要。
4. 报告查看与下载入口：放到报告生成中心实现后再接入门户。

二、权限与用户管理
1. 平台管理员用户管理接口：用户列表、禁用/启用用户、重置密码。
2. 角色分配接口：给用户授予或撤销 platform_admin/evaluator。
3. 审计日志：记录管理员创建平台预置模型、数据集、Key 池等操作。

三、模型服务中心
1. 平台模型 Key 池调度：已完成最小轮询接入；仍需补权重调度、失败重试和无可用 Key 时的重排队。
2. Key 级限流：按 secret_ref 做 RPS/RPM 限制，当前尚未实现。
3. 用户级限流：保证多用户共享平台 Key 池时的公平性。
4. Key 健康状态：上游限流、失效、错误率、熔断和恢复。
5. 模型运行状态监控：模型可用性、平均延迟、错误率。
6. 本地模型注册与状态探测。

四、任务调度与执行
1. 当前只做了全局 queued + running 数量限制，尚未实现自动调度 pending 任务。
2. 任务取消接口。
3. 任务优先级。
4. 批量任务执行。
5. 定时任务执行。
6. 任务日志查询接口。
7. Worker 心跳、容量和队列长度监控。

五、数据资源中心
1. 数据标签与分类管理。
2. 数据版本管理。
3. 数据统计分析与检索查询。
4. 数据导入导出管理。
5. CSV 数据集读取适配。
6. 音频/视频多模态数据完整读取与执行适配。

六、攻防算法中心
1. 攻击算法管理接口。
2. 防御算法管理接口。
3. 算法参数配置和版本管理。
4. 攻防策略组合配置。
5. 算法服务发布与调用。
6. 攻防效果评估管理。

七、评测分析中心
1. 安全风险评估。
2. 模型鲁棒性评估。
3. 模型可靠性评估。
4. 攻击成功率分析。
5. 防御有效性分析。
